# 用户属性扩展

::: warning

内置消息使用 `ACTION_CARD` 类型，钉钉对这类消息的 @ **在手机端不高亮、也不可点击**（通知会正常送达）。
这是钉钉的既有行为，详见 [@ 人](./at-mention.md)。

:::
